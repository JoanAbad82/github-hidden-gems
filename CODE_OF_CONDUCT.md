# Code of Conduct

## Our standard

GitHub Hidden Gems is a technical research and open-source engineering project.
Participation should remain respectful, evidence-oriented, and useful to the
work.

Expected behavior includes:

- discussing ideas, code, evidence, and trade-offs rather than attacking people;
- giving reproducible examples when challenging a technical claim;
- acknowledging uncertainty and correcting mistakes when evidence changes;
- respecting privacy, confidentiality, and security boundaries;
- avoiding harassment, discrimination, intimidation, spam, or deliberately
  disruptive behavior.

## Research-specific expectations

External repositories, issue content, links, prompts, and contributed evidence
must be treated as untrusted input. Do not pressure maintainers or contributors
to execute third-party code, reveal credentials, weaken safety controls, or
bypass the project's validation boundaries.

Disagreement is welcome. Unsupported certainty, fabricated evidence, and
attempts to manipulate scoring or validation results are not.

## Scope

This code applies to repository issues, pull requests, reviews, discussions,
and other project-managed collaboration spaces.

## Enforcement

Project maintainers may edit, hide, reject, or remove contributions that violate
these expectations, and may restrict participation when necessary to protect
the project or its contributors.

When possible, concerns should be raised through the least public appropriate
channel. Security-sensitive reports should follow [SECURITY.md](SECURITY.md).
